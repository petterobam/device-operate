# 网络足迹监控

## 目标

在“我的 macOS → 快捷访问 → 网络足迹”中，把本机应用和服务的网络活动汇总成两层视图：

1. **应用视角**：哪个应用、Helper 进程或后台服务连接了哪个目标 IP。
2. **空间视角**：目标 IP 属于哪个国家、省级地区或城市，并映射到世界地图。

连接分为三类：

- **外联**：本机进程主动连接到远端。
- **入站**：远端已连接到本机监听端口。这里统计的是已经建立/被接受的连接，不是所有到达网卡的扫描包。
- **监听**：本机进程正在等待连接的套接字，用于理解本机暴露了哪些服务。

## 当前实现

### 数据采集

- `lsof -nP -iTCP -iUDP -FpcnPT` 读取进程 PID、协议、本地/远端地址、端口和 TCP 状态。
- `ps -axo pid=,comm=` 把 PID 映射到可执行文件；嵌套 Helper 会通过 `.app` bundle 归并到主应用。
- 对监听端口建立索引，用同一个进程的本地端口判断入站还是外联。
- 5 秒轮询一次，只读，不注入进程，不抓取数据包。

### 代理透视

macOS 上使用 Clash/Mihomo、Surge 等系统代理时，应用在 `lsof` 中通常只会显示 `应用 → 127.0.0.1:代理端口`。本实现会：

1. 从运行参数自动发现 Mihomo/Clash 的 Unix 控制 socket。
2. 读取其本地 `/connections` API。
3. 用 `sourcePort`、`processPath`、`remoteDestination` 和 `host` 还原应用的最终目标。
4. 过滤掉代理进程自身的重复出口连接，避免把代理节点当成应用目标。

如果没有可用的代理控制接口，地图会显示代理进程的实际出口，并标注“未检测到代理控制接口”。

### IP 归属地

- 默认使用 `ipwho.is` 查询公网 IP，得到国家、地区（省级）、城市、经纬度、ASN/组织。
- 私有地址、回环地址、链路本地地址和局域网地址不会发送到外部服务。
- 归属地结果缓存到 `~/.config/device-operate/network-geo-cache.json`，成功结果缓存 30 天，失败结果缓存 1 小时。
- 每轮最多补充 20 个新 IP，使用 3 个并发请求，避免短时间打出大量外部请求。
- 用户可在界面关闭“IP 归属地查询”；关闭后仍保留 IP/端口/应用关系，但没有地图落点。

发送到定位服务的只有公网 IP，不发送进程名、域名、URL、账号或流量内容。

### 聚合与保留

- 当前会话保留最近 10 分钟出现过的流（界面可查看配置值）。
- 相同 `应用 + 方向 + IP + 端口 + 协议` 的多条 socket 会合并，并显示 `connectionCount`。
- 进程消失后，流会在保留窗口内标记为非活跃，方便看到刚结束的连接。
- CoreSimulator 运行时中的进程会显示为“iOS 18.5 模拟器 · cloudd”这类名称，而不是误认为一个 iOS 应用；模拟器路径中的空格不会再把整条路径截断成 `iOS`。
- 地图按国家 + 省级地区聚合，避免一个地区叠出几十个点。
- 地图以本机公网出口为中心重新投影，主机固定在画布中心；外联路径从本机指向目标，入站路径从远端指回本机，避免跨日界线时出现反向或绕边的连线。

### HTTP API

```text
GET   /api/network-monitor/snapshot    当前聚合快照
POST  /api/network-monitor/refresh     立即扫描
GET   /api/network-monitor/config      读取隐私/保留配置
PATCH /api/network-monitor/config      更新配置
```

配置写入：

```text
~/.config/device-operate/network-monitor-config.json
```

### 前端

- 左侧快捷访问新增“网络足迹”入口。
- 世界地图使用本地打包的 Natural Earth `world-atlas` 数据，按 D3 等经纬投影绘制，不依赖在线地图瓦片。
- 地图落点支持外联/入站/双向三种颜色，显示本机公网出口到目标的连线。
- 应用列表、国家/地区排行、连接明细可搜索、筛选和切换是否包含局域网连接。

## 明确的边界

- **不是防火墙，也不是 IDS**：不拦截、不修改连接。
- **不是 pcap**：不读取 HTTP/HTTPS 请求正文、账号、Cookie 或载荷。
- **入站不包含被丢弃的扫描包**：要统计 SYN 扫描、被 pf 拒绝的连接，需要 root 权限的 pf 日志或 Network Extension/pcap。
- **特权进程可能不完整**：普通用户运行 `lsof` 时，部分 root-only 服务或受保护进程的套接字可能不可见。
- **代理不是 100% 可还原**：只有代理提供本地控制 API 且本机能访问时，才能把目标归属回具体应用。
- **归属地是 IP 级近似**：CDN、Anycast、云厂商出口和 IP 数据库更新都会导致国家/省份误差。
- **仅在应用运行时监控**：当前版本不安装独立系统守护进程；关闭“我的 macOS”后停止扫描。

## 后续路线

### P1：长期留存与告警

- 将聚合流写入按天滚动的 JSONL/SQLite，支持 7 天/30 天趋势。
- 对“新出现国家/地区”“异常夜间外联”“未授权监听端口”“大量入站来源”做告警。
- 增加数据保留期和清空入口，确保隐私策略可控。

### P2：系统级完整性

- 增加可选的特权 helper，以 root 权限读取完整 socket/进程映射。
- 通过 `pf` 日志或 Apple Network Extension 增加被拒绝的入站连接统计。
- 解析 VPN、代理链、DNS 与 SNI，增强“域名 → 代理节点 → 最终 IP”的可解释性。

### P3：主动诊断

- 对每个应用给出目标 ASN、云厂商、TLS 证书域名和连接时长。
- 支持按应用/国家/端口创建允许与阻断规则；执行层单独做成受确认的系统变更，不与只读监控混合。
- 支持多设备上报与跨设备地图。
